Get started

One cable install, then everything from the phone.

  1. Install NBT Manager

    Once per car, with the desktop installer over an ENET cable, or from the phone app over a Wi-Fi ENET adapter.

  2. Pair your phone

    The NBT Manager app for Android. Join the car's Wi-Fi and compare six digits with the car. No binary release yet: build it from source.

  3. Install apps

    Open Get apps, download, install. The car checks each package's signature and the driver confirms it on iDrive. A bad update rolls back by itself.

  • Approved on the car

    The phone only asks. Every install and removal is confirmed on iDrive.

  • Safe updates

    A new version must start and stay healthy, or the previous one comes back.

  • Your files

    Send games and files from the phone, or import them from a USB stick.

  • The car's controls

    The iDrive controller, a USB gamepad and the car's speakers.

  • Live settings

    Change an app's settings from the phone while it runs.

  • Seven languages

    English, French, German, Italian, Spanish, Chinese and Japanese.
